# Prompt para reanudar

Retomá el frontend B2B de DISTRICO desde su estado actual, sin reconstruirlo.

1. Leé `CLAUDE.md`, `docs/PROGRESS.md` y `docs/MASTER.md`.
2. Comprobá `git status --short` y respetá cambios existentes.
3. Abrí solamente los archivos indicados por la próxima acción y el prompt de la tarea correspondiente.
4. Si la tarea está parcial, terminá esa tarea antes de iniciar otra.
5. No cambiar backend, no inventar endpoints y no mezclar datos reales/simulados.
6. Ejecutá las comprobaciones pertinentes y actualizá el registro al cerrar.

No reinstales dependencias si ya están disponibles. No releas todo el repositorio ni todos los prompts. Informá qué tarea retomás y continuá con la siguiente acción documentada.
