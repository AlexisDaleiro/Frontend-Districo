# Prompt para pausar

Detené la ampliación del alcance y prepará la continuidad. No elimines cambios ni hagas commit automáticamente.

Actualizá `docs/PROGRESS.md` con:

1. Tarea actual y objetivo concreto.
2. Qué quedó terminado y qué quedó parcialmente implementado.
3. Archivos modificados y decisiones tomadas.
4. Comandos de prueba ejecutados y resultado real, incluyendo fallos.
5. Dependencias externas o información pendiente.
6. Próxima acción exacta y archivo por el que debe empezar la nueva sesión.

Comprobá `git status --short`. Si es posible dejar el código compilando dentro del trabajo ya empezado, hacelo. Si no, describí el error exacto y cómo reproducirlo. No consumas el resto de la sesión explorando fases futuras.

Respondé con un resumen breve y el nombre del prompt para retomar.
