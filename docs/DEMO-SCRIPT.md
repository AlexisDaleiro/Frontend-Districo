# Guion de reunión · 10–15 minutos

1. Reiniciar demo. Mostrar inicio en móvil: necesidades, banner, marcas y selección breve. Entrar por Arenas sanitarias y probar búsqueda/filtros.
2. Mostrar una ficha pública: presentaciones visibles, precios reservados a clientes aprobados.
3. Enviar solicitud con datos ficticios. Entrar como administrador, revisar la solicitud y aprobarla. Volver a ingresar con el correo solicitado y contraseña demo.
4. Abrir un producto, elegir cantidad válida, guardar carrito. Mostrar validación de mínimos y múltiplos con snacks.
5. Enviar pedido. Mostrar número, importe y consulta posterior. Aclarar que pago y entrega se coordinan comercialmente.
6. Ingresar con la cuenta de pago pendiente. Repetir pedido y mostrar la aceptación de revisión manual.
7. En administración, consultar pedido, revisar detalle y cambiar estado. Mostrar el ajuste de reservas en existencias.
8. Mostrar edición de precio, presentación e imagen por URL. Crear una promoción simple y una recomendación de carrito.
9. Mostrar diferencias de permisos entre cliente normal y cliente veterinario, sin afirmar reglas comerciales reales sobre los productos seleccionados de demostración.

Si la API real falla, mostrar el error, pasar deliberadamente a la URL demo separada y explicar que allí las operaciones son simuladas. No fingir continuidad entre ambos entornos.

Antes de la reunión: usar un navegador limpio, verificar ambos enlaces, confirmar recursos y stock de prueba con el socio, comprobar modo indicado en pantalla y evitar mostrar datos personales reales.
